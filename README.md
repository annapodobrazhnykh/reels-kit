# reels-kit — рилсы с Claude Code или Codex

Набор скиллов, с которыми ИИ-агент сам монтирует рилсы «говорящая голова» из видео с iPhone (паузы, «ээ», субтитры, зумы, вставки, звуки, музыка), делает обложки, придумывает идеи по трендам и публикует посты в Instagram, YouTube Shorts и X.

| Скилл | Что делает |
|---|---|
| `short-video-strategy` | что снимать: тренды, хуки, идеи, сценарии, план съёмки |
| `short-video-editing` | монтаж по этапам: черновик → материалы → вставки, зумы, звуки → музыка |
| `reel-covers` | обложки с текстом, которые не обрезаются в сетке профиля |
| `short-video-publishing` | подписи, расписание, публикация через Upload-Post, статистика |

Нужен Mac на чипе M1 или новее и Claude Code (приложение Claude, вкладка Code; подписка Pro или Max) или Codex (подписка ChatGPT Plus или выше).

## Установка

### Способ 1: одной командой (если есть Node.js)

```bash
npx skills add annapodobrazhnykh/reels-kit
```

Выбери своих агентов (Claude Code, Codex и др.). Потом открой агента и напиши:

> Доставь программы для набора рилсов: прочитай README в github.com/annapodobrazhnykh/reels-kit и проведи меня по настройке

Скиллы без программ не работают: нужны ffmpeg, Whisper и Python-библиотеки. Агент поставит их сам.

### Способ 2: архивом

Скачай [reels-kit.zip](https://github.com/annapodobrazhnykh/reels-kit/releases/latest/download/reels-kit.zip) в «Загрузки» (или возьми у того, кто поделился), открой Claude (вкладка Code) или Codex в папке «Загрузки» и напиши:

> Установи набор для рилсов из загрузок reels-kit.zip — прочитай внутри README и проведи меня по настройке

Дальше агент всё сделает сам и будет спрашивать только то, что нужно от тебя: пароль от Mac, пару слов о твоём блоге и хочешь ли ты подключить публикацию.

## Для агента

Тебя попросили установить этот набор. Открой `УСТАНОВКА.md` (в папке набора или по адресу https://github.com/annapodobrazhnykh/reels-kit/blob/main/УСТАНОВКА.md) и иди по нему шаг за шагом. Коротко:

- **Claude Code** → `zsh setup.sh`: программы + скиллы в `~/.claude/skills`.
- **Codex** → `zsh setup.sh codex`: программы + скиллы в `~/.agents/skills`, плюс коннекторы через `~/.codex/config.toml`.
- **Скиллы уже стоят после `npx skills add`** → `zsh setup.sh tools`: только программы. Папки набора тогда нет — склонируй репозиторий во временную папку.
- Архив ещё не распакован → `ditto -x -k ~/Downloads/reels-kit.zip ~/Downloads/`. Если скачали «Code → Download ZIP» с GitHub, папка будет называться `reels-kit-main`.

Рабочая папка для роликов у всех агентов одна: `~/Desktop/shortVideos`.

## Что внутри

- `skills/` — 4 скилла.
- `setup.sh` — ставит ffmpeg-full, whisper.cpp, yt-dlp, gh, Python-окружение и модель Whisper (1,6 ГБ), создаёт рабочую папку и кладёт скиллы на место. Повторный запуск безопасен.
- `sfx/`, `brand.md` — звуки и стиль субтитров для рабочей папки.
- `AGENTS.md` — памятка для Codex в рабочей папке.
- `УСТАНОВКА.md` — пошаговая инструкция для агента.

Методика стратегии и публикации — пересборка открытых промптов Нади Зуевой ([nestyme/awesome-prompts](https://github.com/nestyme/awesome-prompts)); подробности — в самих скиллах.
