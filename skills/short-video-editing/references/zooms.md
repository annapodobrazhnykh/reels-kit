# Зумы

## Логика (туториал Ани + её правки)
Из туториала (видео было записью экрана с защитой, разобран по речи):
1. Хук: первый ключ увеличен, через короткое расстояние нормальный масштаб → **резкое отдаление в самом начале**.
2. Акцентное слово: два ключа рядом, на втором приближено → **резкий зум**.
3. В конце отрезка ключ с исходным масштабом → **резкое приближение и плавное отдаление**, нет отскока между кадрами.

## Параметры, на которых Аня сказала «зумы ок»
- `HOOK_ZOOM = (0.20, 0.45)`: старт ×1,20, ease-out к 1,0 за 0,45 с.
- Акцент: `(t0, amp, t1)` — t0 начало акцентного слога (секунды ролика), amp 0,10–0,18 (0,18 только на самый сильный), t1 — конец фразы. SNAP 0,15 с ease-out внутрь, затем **линейно** наружу до t1. Косинусное отдаление выглядело как «завис, потом поехал» — линейное лучше.
- Центр зума: по горизонтали середина, по вертикали 0,32 высоты (лицо).
- Рендер: фильтр `perspective` с выражениями от `in/30` (номер кадра) по всему склеенному таймлайну — отдаление спокойно идёт через склейки.

## Где ставить
- Ищи **совпадение громкого/высокого слога и жеста рук**: `work/accents.py`. Тайминги Whisper не годятся: в london1 зум «на отказалась» по Whisper реально попадал на «и ради этого».
- Внутри фразы ударение одно; между ударениями провал громкости. Пример: «когда тебе настолько всё не нравится» — слоги «настОлько» (долгий подъём тона), «всё не» (провал!), «нрАвится» (−28,5 дБ, на 6 дБ громче соседних, 281 Гц, рука в верхней точке). Зум на «всё не» Аня назвала «не попал в акцент»; на «нрАвится» — ок.
- Подтверждай жест кадрами из `proxy.mov` по **времени исходника** (offsets.json), а не ролика.
- «Трогает лицо / поправляет волосы» = движение без смысла, не акцент.
- Не чаще раза в ~7 с; не рядом со вставками («сразу перед этим скрин визы, сразу после — ящики, слишком много»); в финале один.

## Серии 3–5 (2026-11)
- Стараться ставить на **активное движение головой или рукой** вместе с ударным слогом; `accents.py` даёт кандидатов, кадры подтверждают движение.
- **Не на склейке**: зум, начавшийся за 0,25 с до стыка («чем тогда») или пролетающий через стыки («до полутора лет»), Аня назвала неудачным. Начало ≥0,4 с от стыка, конец до следующего стыка; шаблон печатает `WARNING zoom … touches the join`. Стыки — `work/offsets.json`.
- Удачные примеры серии 4: «РАботаю», «загуГЛИТЬ», «выступЛЕние», «ВОТ вклад»; серии 5: «начните соБИРАТЬ», «ОТ нескольких месяцев», «в ЖИЗни».

## Ошибки, которых больше не повторять
- `scale` + `crop` с `2*trunc(...)` на каждом кадре → шаги 2/4 px, дрожь. Только `perspective`.
- Зум на начало куска нарезки вместо слова.
- Зумы по «важным словам» из текста, 2–3 подряд за несколько секунд.
