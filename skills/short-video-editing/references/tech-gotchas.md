# Технические грабли (все реально случились)

| Симптом | Причина | Решение |
|---|---|---|
| Нет фильтров `subtitles`/`zscale` | brew `ffmpeg` без libass/zimg | `/opt/homebrew/opt/ffmpeg-full/bin/ffmpeg` |
| `-filter_complex_script` не найден | ffmpeg 9 его убрал | `-/filter_complex file.txt` |
| Блёклые/кислотные цвета | iPhone HLG HDR | zscale→linear→hable→bt709, sat 0.85 |
| Субтитры курсивом | libass по «Avenir Next» берёт BoldItalic | `AvenirNext-Bold` (PostScript-имя), Bold=0 |
| Хук-заголовок не рисуется | событие нулевой длительности в .ass ломает последующие слои | длительность ≥ 0,1 с |
| Слова в субтитрах в неправильном порядке | Whisper ставит первые слова фразы на одну метку | растянуть такие группы, монотонный порядок |
| Перенос строки не работает | `WrapStyle: 2` | `WrapStyle: 0`, ≤17 символов |
| Белые субтитры теряются на светлой вставке | нет подложки | `Outline 7` &H70000000 + `\blur9` |
| Дрожь при плавном зуме | `scale`+`crop` с округлением | `perspective` (субпиксельно) |
| Мигающий кадр в конце вставок | `-t dur` у входов → слои кончаются в разные кадры | `-t dur+0.5`, конец через `enable` |
| Финальное слово «съедено» эффектом | низкий бум под словом | −13 дБ, lowpass 220 Гц |
| Пропали тихие концы фраз | порог тишины слишком высокий | ≤ −40…−45 дБ, проверка распознаванием нарезки |
| Whisper выдаёт «Продолжение следует…» на куске | там нет речи (вдох/шум) | можно вырезать |
| Whisper `-ml` режет русские слова пополам | лимит в байтах | добавлять `-sow` |
| Запись экрана с плеера — чёрная | DRM | разбирать по звуку (Whisper) |
| Распознавание длинного файла пропустило фразу | сбой Whisper | перепроверить коротким отрывком перед выводами |
| `brew: command not found` в терминале Ани | Homebrew не в PATH (.zprofile не правили) | полные пути; ей — `eval "$(/opt/homebrew/bin/brew shellenv zsh)"` |
| `accents.py`: проверка кадров жестов «не те» | `proxy.mov` во времени исходника | переводить через `offsets.json` |

## Вырезать союз/слово внутри фразы (london1 short, 2026-10-27)
- **Whisper не слышит, что союз остался.** На склейке «Но + [и]весной» он писал «Но весной», хотя Аня слышала «но и весной». У неё союзы бывают протяжные: «Иии…» длилось 0,8 с (28,46–29,3). Проверяй так: распознай кусок, начиная с кандидатной точки, **отдельно, без склейки**. Сдвигай точку, пока союз не пропадёт из текста («И весной» → «Весной»), а потом подтверди провалом громкости.
- **Пауза из тишины комнаты.** Перед вставкой проверь её уровень: в «тишине» был вдох, на 5 дБ громче фона, и после loudnorm он звучал как лишний звук.
- **Звук-эффект (бум, свиш) не ставь в паузу перед словом**: он слышится как «лишний звук перед словом». Ставь его на само слово или убирай.
