# Короткие видео (рилсы, шортсы)

Это рабочая папка блога: ролики, планы, обложки и статистика. Для любой задачи про видео используй скиллы `short-video-*` и `reel-covers` (у Codex они в `~/.agents/skills`, у Claude Code — в `~/.claude/skills`):

- `short-video-strategy` — что снимать: тренды, хуки, идеи, сценарии, план съёмки, журнал экспериментов;
- `short-video-editing` — монтаж «говорящей головы» по этапам: черновик → материалы → вставки, зумы, звуки → музыка;
- `reel-covers` — обложки;
- `short-video-publishing` — подписи, расписание, публикация через Upload-Post, статистика.

Перед работой открой `SKILL.md` нужного скилла и следуй ему, даже если в просьбе нет слова «скилл».

Общие правила:
- Говорить с человеком на его языке и на нём же делать субтитры, тексты, обложки и подписи (язык блога — в `_strategy/brief.md`).
- Этапы не склеивать. После каждого показывай результат файлом и жди «ок» или правки.
- Ничего не публиковать и не ставить в расписание без явного «да» на конкретный пост.
- Говорить просто, без технических подробностей, если о них не спросили.
