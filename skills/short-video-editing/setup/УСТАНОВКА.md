# Инструкция для агента: установить набор для рилсов

Ты читаешь это, потому что набор `reels-kit` нужно настроить: пользовательница попросила его установить или впервые попросила что-то по рилсам, а программ ещё нет. В последнем случае после настройки вернись к её просьбе. Она не программист: проведи её по шагам сам, коротко и по-человечески. Всю инструкцию ей не показывай, говори только, что происходит сейчас и что нужно от неё. Говори с ней на её языке (на котором она пишет), хоть эта инструкция и на русском. Технические шаги делай сам; от неё нужны только пароль от Mac, вход в аккаунты и ответы на вопросы. Если тебе не хватает прав (песочница, запись в `~/.claude`, `~/.agents`, `/opt/homebrew`, сеть), попроси разрешение на команду, а не обходи ограничение.

`SETUP` — папка, где лежит этот файл: `short-video-editing/setup/` внутри скиллов (после `npx skills add` это обычно `~/.agents/skills/short-video-editing/setup`, в распакованном zip — `reels-kit/skills/short-video-editing/setup`).

Команда установки — `zsh "$SETUP/setup.sh"`, режим скрипт выбирает сам:
- скиллы уже стоят у агента (поставили через `npx skills add`, или ты читаешь этот файл из папки скиллов) → ставит только программы;
- запущен из распакованного zip или клона → ставит программы и копирует скиллы в `~/.claude/skills` (Claude Code). **Если ты Codex — добавь `codex`**: `zsh "$SETUP/setup.sh" codex`, скиллы встанут в `~/.agents/skills`. Если скиллы уже стоят у агента, аргумент не нужен.

## 1. Проверка
- `uname -m` должен быть `arm64`. Если нет, честно скажи, что набор рассчитан на Mac с чипом M1 и новее, и остановись.
- Свободно не меньше 5 ГБ (`df -h ~`).

## 2. Установка программ
Если Homebrew (`/opt/homebrew/bin/brew`) уже стоит, запусти команду установки сам, в фоне: пароль не понадобится, всё займёт 10–20 минут, модель Whisper весит 1,6 ГБ. Скажи ей: «Ставлю программы для монтажа, это минут 15. Пока ставится — расскажи немного о себе» — и **сразу, не дожидаясь конца установки**, задай вопросы из шага 4.
Если Homebrew нет, его установщику нужен пароль от Mac. Тогда запусти команду в терминале, который она видит (у Claude Code — панель терминала, `run_in_terminal`, если есть), или дай ей одну строку для приложения «Терминал» (⌘+Пробел → «Терминал»), с полным путём к `setup.sh`. Предупреди: «Попросит пароль от Mac. Введи его и нажми Enter — символов видно не будет, так и должно быть. Потом 10–20 минут всё ставится само. Когда увидишь „Done“, напиши мне». Дождись её сообщения.
В конце скрипт печатает четыре строки с ✓. Если какой-то нет, разберись и почини сам. Скрипт можно запускать повторно.

## 3. Рабочая папка
Скажи ей открывать для всех будущих задач про рилсы рабочую папку `Desktop/shortVideos`: там лежат ролики, планы и статистика, скиллы ищут её по этому пути. Там уже лежат `AGENTS.md` (для Codex) и `CLAUDE.md` (для Claude Code) с правилами работы. Если в новой сессии скиллы не видны — перезапустить приложение.

## 4. Адаптация под неё
Скиллы (`short-video-*`, `reel-covers` в папке скиллов твоего агента) написаны под Аню, которая ими поделилась. Спроси одним сообщением:
- как её зовут;
- про что её блог и для кого (темы, аудитория, на каком языке ролики);
- на каких площадках она публикуется (Instagram / YouTube Shorts / X / TikTok);
- что точно нельзя показывать в роликах.

Потом перепиши скиллы под неё. Имя «Аня» и её личные темы (Лондон, виза талантов, конкретные серии) замени на её или убери. Методику, этапы монтажа, технические правила и цифры **оставь**. `references/feedback-log.md` в short-video-editing уже пустой: туда будут копиться её собственные правки. В конце проверь `grep -rn 'Ан[яиеюй]'` по папкам этих скиллов — результат должен быть пустым.
Затем создай `~/Desktop/shortVideos/_strategy/brief.md` по шаблону из `short-video-strategy/references/templates.md` и впиши туда её ответы. Бриф нужен обязательно, даже короткий: по нему скиллы понимают, что набор настроен. Если отвечать не хочет — запиши имя и «бриф заполним позже».
Предупреди одной строкой: если когда-нибудь обновлять набор командой `npx skills update`, её правки в скиллах перезапишутся версией про Аню — тогда попросить агента снова адаптировать скиллы по брифу.

## 5. Коннекторы (по желанию)
Объясни в двух строках и спроси, нужно ли:
- **Apify** — поиск вирусных роликов и хуков. Бесплатно примерно $5 в месяц, один прогон стоит $1–5.
- **Upload-Post** — публикация и статистика. Бесплатный тариф с лимитом загрузок, TikTok только на платном.

Без них монтаж и обложки работают.

**Claude (приложение):** Настройки → Коннекторы → найти Apify / Upload-Post → подключить и войти в аккаунт.

**Claude Code в терминале:** `claude mcp add --scope user --transport http apify https://mcp.apify.com` и `claude mcp add --scope user --transport http upload-post https://mcp.upload-post.com/mcp`, потом в Claude Code `/mcp` → выбрать сервер → войти.

**Codex:** добавь MCP-серверы в `~/.codex/config.toml` (если такие таблицы уже есть, не дублируй):

```toml
[mcp_servers.apify]
url = "https://mcp.apify.com"

[mcp_servers.upload-post]
url = "https://mcp.upload-post.com/mcp"
```

Потом пусть она войдёт в аккаунты: `codex mcp login apify` и `codex mcp login upload-post` (откроется браузер), или приложение Codex предложит вход само после перезапуска. Если вход через браузер не сработал — API-ключи: она копирует ключ в кабинете (Apify → Settings → API & Integrations, Upload-Post → API Keys) и сама вписывает в `~/.zshenv` строкой `export APIFY_TOKEN=…` / `export UPLOAD_POST_API_KEY=…`. Ключ не должен попасть в чат. Ты добавляешь в таблицы `bearer_token_env_var = "APIFY_TOKEN"` и `bearer_token_env_var = "UPLOAD_POST_API_KEY"`, затем перезапуск Codex.

Проверь, что инструменты появились: у Apify есть `search-actors`, у Upload-Post — `list_users`. Instagram, YouTube и X подключаются уже внутри Upload-Post: ссылку даст `get_connect_link`, когда дойдёт до публикации.

## 6. Финал
Если настройка началась с её просьбы (например, «смонтируй рилс») — не прощайся, а сразу вернись к ней: заведи папку ролика `~/Desktop/shortVideos/videos/<ГГГГ-ММ-ДД>_<короткое-имя>/` и попроси видео (в чат или в эту папку). Иначе —
Скажи, что всё готово, и как пользоваться — 3 строки:
- «что снимать на этой неделе?» — идеи и план съёмки;
- кинуть видео в `~/Desktop/shortVideos` и написать «смонтируй рилс» — черновик, потом украшения, музыка, обложка;
- «напиши подписи и запланируй» — публикация (только после её «да»).

Если ставили из архива — архив и распакованную папку можно удалить. Предложи это, но без её согласия не удаляй.
