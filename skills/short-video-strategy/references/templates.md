## Идея (ideas/YYYY-MM-DD.md)
```markdown
### Идея N — короткое имя
- **Источник паттерна**: какой ролик/формат и почему сработал
- **Референсы**: [@handle](URL) — просмотры — что именно брать (хук/кадр/темп). Нет → «НЕТ — общий паттерн, риск выше»
- **Первый кадр (0–1,5 с)**: что на экране и в звуке
- **Хук (0–5 с)**: первая фраза дословно (голосом; заголовок-хук поверх видео Аня не ставит)
- **Формат**: id из hook-formats.md
- **«Ага»-момент**: на какой секунде ценность
- **CTA**: неявный (вопрос в конце / серия) или явный
- **Съёмка**: просто / нужны вставки / нужна локация
- **Гипотеза эффекта**: высокий/средний/низкий + почему
- **Варианты для теста**: 2–3 угла
```

## Вариация
```markdown
### Идея-N-vA — имя
- **Родитель**: Идея-N от дата, результат: N просмотров (аккаунт: новый/рабочий)
- **Зафиксировано**: хук, формат, смысл, CTA
- **Меняем**: одна ось (место / образ / темп / время суток / энергия)
- **Гипотеза**: какую новую аудиторию откроет
```
