# Стратегия коротких видео (ресёрч → хуки → идеи → съёмка)

`<скиллы>` в командах ниже — папка, где лежат этот и соседние скиллы (у Claude Code обычно `~/.claude/skills`, у Codex — `~/.agents/skills`).

Пересборка открытых скиллов Нади Зуевой (`trendwatch`, первая половина `ugc-hooks`, github.com/nestyme/awesome-prompts) под личный блог Ани и наши инструменты. Методика её, код и формулировки наши: в репозитории нет лицензии, поэтому код не копировали.

**Чем отличается от оригинала:** у Нади — промо приложения (1–3 с реакции → запись экрана, музыка без голоса). У Ани — **говорящая голова и личная история** (сериал «переезд в Лондон», AI-продакт, карьера, фаундерство), с голосом и субтитрами. Поэтому механики хука переносим, а формат «реакция + скринкаст» — лишь один из многих.

## Где лежит состояние (не в папке скилла)
`~/Desktop/shortVideos/_strategy/`:
- `brief.md` — живой: темы, аудитория, язык, платформы, цели, пороги победы, ограничения (что не показываем).
- `current-plan.md` — живой: что снимаем и публикуем сейчас, дерево решений.
- `experiments.md` — **главный накопительный актив**, только дописывать сверху. Читать перед любой генерацией идей.
- `creators/<platform>_<handle>.md` — разбор отслеживаемых авторов.
- `trends/YYYY-MM-DD/` — выгрузки, `ranked.csv`, `hooks/` (раскадровки), `report.md`.
- `ideas/YYYY-MM-DD.md` — идеи и вариации (исторические, не править задним числом).

## Принципы (почему так)
1. **Сначала ищи сама, спрашивай только решения.** Темы, ссылки и ники находятся поиском, памятью и прошлыми файлами. У Ани спрашивай цели, вкус, что ей комфортно снимать и подтверждение гипотез.
2. **Ищи по фразам ниши, хук вытаскивай потом.** «переезд в лондон», «уволилась из корпорации», «AI product manager day in life», «moving to london alone», а не формулировки хуков: поиск по хуку находит только этот хук.
3. **Хук читай с кадров, а не из подписи.** Текст на экране 0–3,5 с + первые 6 с речи. Подпись обычно набор хэштегов.
4. **Окно 6 месяцев.** Хуки клонируются за недели. Для звуков — только `rising`/`peak` (<30 дн.).
5. **Формат, а не автор.** 500 тыс. просмотров у миллионника доказывают популярность автора, а не силу формата. В идеи идут ролики, которые «вывез формат» (`rank.py`: ≥2× медианы автора или ≥0,5× подписчиков). Аккаунты >1M подписчиков не берём, лучшие 10k–250k.
6. **Комментарии — готовые хуки.** Самый залайканный вопрос или боль под чужим вирусным роликом — готовая тема видео.
7. **Победителей варьируем, проигравших убиваем.** Ролик прошёл первый порог (для нового аккаунта ~1000 просмотров) → фиксируем хук, формат и смысл, меняем одну ось: место, образ, темп, время суток. Новые идеи нужны для холодного старта, рост дают вариации.
8. **Якорные посты не варьируем.** История основателя / «почему я уехала» — 1–2 в квартал. Вариации — для трендов, «до/после», списков, «я попробовала X».
9. **Подстраивай идеи под то, что реально снимается.** Аня снимает сама на iPhone дома/в городе, монтирует агент (`short-video-editing`). Идея, которой нужна съёмочная группа или чужие лица, отпадает.
10. **Чужое не используем.** Референсы — только для механики. Чужие кадры, лица и звуки с голосом в посты не идут.

## Процесс

### 0. Бриф (первый запуск или раз в месяц)
Если нет `_strategy/brief.md` — собери черновик из памяти и прошлых файлов (london1, LinkedIn-позиционирование, телеграм-канал), затем задай до 4 вопросов одним сообщением (или `AskUserQuestion`, если он есть): главная цель (подписчики / клиенты / найм / узнаваемость), язык и аудитория по платформам (русскоязычная / английская / обе), что считаем победой, что точно не показываем. Шаблон — `references/templates.md`.

### 1. Сбор (≈ $1–5 за прогон; **покажи запросы и примерную цену до запуска**)
Через Apify MCP (`call-actor`; перед первым вызовом `fetch-actor-details` → входная схема):
| Площадка | Актор | Как |
|---|---|---|
| TikTok (лучший источник трендов, даже если сама там не постишь) | `clockworks/tiktok-scraper` | `searchQueries`, `searchSection:"/video"`, `videoSearchSorting:"MOST_LIKED"`, `videoSearchDateFilter:"LAST_6_MONTHS"`, 12–30 на запрос |
| Instagram Reels | `data-slayer/instagram-search-reels` (по слову) → `apify/instagram-reel-scraper` (по найденным авторам, `onlyPostsNewerThan`) | подписчиков берёт `apify/instagram-scraper` с `addParentData` |
| YouTube Shorts | `yt-dlp "ytsearch50:<фраза> #shorts" --flat-playlist -J` (бесплатно) → `streamers/youtube-shorts-scraper` по каналам | фильтр длительности ≤ 60 с |
| X | `apidojo/tweet-scraper` | `searchTerms`, `onlyVideo:true`, `minimumRetweets`, язык |

30–60 запросов: темы × языки (RU + EN), фразы боли и жанра. Сохраняй сырые выгрузки в `trends/<дата>/raw/`.

### 2. Ранжирование
```bash
python3 <скиллы>/short-video-strategy/scripts/rank.py trends/<дата>/raw/*.json --out trends/<дата>/ranked --min-views 50000
```
Нормализует поля всех четырёх площадок, считает `engagement_score = (лайки + 2·комменты + 3·сохранения + 5·репосты)/просмотры`, свежесть, `vs_account_median`, размер аккаунта и атрибуцию. Читай верх списка, а не всё подряд.

### 3. Хуки с кадров
```bash
python3 <скиллы>/short-video-strategy/scripts/hook_extract.py trends/<дата>/ranked.json --top 40 --out trends/<дата>/hooks
```
На каждый ролик раскадровка 0/0,5/1/1,5/2,5/3,5 с + расшифровка первых 6 с. **Смотри каждую раскадровку сама** (tesseract кириллицу не читает) и записывай: точная строка хука, что в кадре на 0 с (первый кадр — отдельная механика), формат, эмоция.

### 4. Разметка и комментарии
Отнеси каждый ролик к формату из `references/hook-formats.md` (там стартовая таксономия для личного блога; расширяй её новыми форматами). Для 10–20 лучших собери топ-30 комментариев (TikTok: `commentsPerPost`; IG: `apify/instagram-scraper`, тип comments) и выпиши самые залайканные вопросы и боли дословно.

### 5. Отчёт о трендах → `trends/<дата>/report.md`
Топ-5 первых кадров, топ-5 формул хука (шаблоном), топ-3 формата, свежие звуки (если нужны), язык и боли из комментов, 5–10 авторов в отслеживание (`creators/`). Можно сделать доску: страницу-артефакт с карточками «раскадровка + хук + просмотры» по форматам.

### 6. Идеи → `ideas/<дата>.md`
Сначала прочитай `experiments.md`: не повторяй проигравшее, держись рядом с победившим. 10 идей по шаблону из `references/templates.md`. В каждой обязательно 1–3 ссылки-референса (без них идея — догадка), первый кадр, хук дословно, где наступает «ага», формат, сложность съёмки, гипотеза. Ранжируй по «эффект × простота». Для сериала (london) учитывай номер серии и обещание из прошлой.

### 7. Сценарии и план съёмки → `videos/<дата>_<slug>/script.md` + страница съёмки
На каждую выбранную идею: первая фраза-хук (2–3 варианта), текст по смыслу (не дословно — она говорит своими словами), список вставок, эмоция первого кадра, 2 референса. Сводная страница съёмки для телефона (артефакт: сцены, хуки, референсы, галочка «снято»). Правила съёмки — `references/shooting.md`.
**Заголовок-хук поверх видео не ставим** (решение Ани 2026-11-10, как и в short-video-editing): на экране только субтитры, вставки и плашки. Хук работает голосом и первым кадром. Обложка с текстом — отдельно (reel-covers).

### 8. Журнал и вариации
После публикации (данные приносит `short-video-publishing`) допиши в `experiments.md`: хук, формат, площадка, метрики, вердикт SCALE / ITERATE / KILL, вывод в одно предложение. Победитель → **режим вариаций**: 5–8 вариантов с зафиксированными хуком, форматом, смыслом и CTA, меняется одна ось. Обнови `current-plan.md`.

### Режимы
- «полный прогон» / «что снимать на неделе» → 0–7
- «что сейчас в трендах про X» → 1–5
- «дай новые хуки» → 6 по последнему сбору
- «залогируй <ролик>» → 8
- «ролик набрал N, что дальше» → 8, режим вариаций
