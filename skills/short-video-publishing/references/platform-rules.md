# Правила площадок (на октябрь 2026 — перепроверять при сомнениях)

## Общие (из опыта Нади + документации)
| Триггер ограничения | Как выглядит | Что делаем |
|---|---|---|
| Одинаковые отпечатки | тот же файл, подпись раз за разом | уникальные подписи и комменты, перекодирование + очистка метаданных |
| Частота на новом аккаунте | 3+ поста в пределах часа, > 3 в день | 1–2 в день, ≥ 4–6 ч, разные слоты по площадкам |
| Одна обложка дважды за день | два поста открываются одним кадром | варианты — в разные дни/площадки |
| Один звук подряд | тот же звук пост за постом | звук от формата; у Ани обычно свой голос + тихие эффекты |
| Спам-подписи | «ссылка в био», «подпишись», ссылки в комментах | вопрос в конце, ≤ 1 эмодзи, без хэштегов |

Не влияет (по наблюдениям): постинг через планировщик/API; один ролик на разных площадках; один слабый пост.

## Instagram Reels
- Площадка разрешает до 5 хэштегов, но Аня их не ставит: подписи без хэштегов.
- `instagramMediaType: REELS`, `instagramShareToFeed: true`; обложка — `instagramCoverUrl` или `instagramThumbOffset`.
- Музыку лучше добавлять в приложении при публикации (лицензия); через API — без трендового звука.
- Подпись: хук первой строкой (видна до «ещё»).

## YouTube Shorts
- ≤ 60 с, вертикаль. Заголовок ≤ 100 символов с ключевыми словами (поиск на YouTube работает).
- «Не для детей» (`youtubeSelfDeclaredMadeForKids: false`), категория 22 (Люди и блоги), язык.
- Хэштеги не ставим (#shorts не обязателен).
- Субтитры файлом повышают доступность и поиск.

## X
- Видео ≤ 2:20 (без подписки), текст ≤ 280. Первая строка — хук.
- Без хэштегов. Ссылки в постах режут охват; ссылка в первом комменте может быть вырезана (смотри `warnings` в `get_status`).
- Хорошо работает видео внутри текстового треда-истории.

## Чек-лист перед постом
- [ ] Финал перекодирован, метаданные очищены
- [ ] Кадры проверены на приватное
- [ ] Подпись уникальна, хук в первой строке, вопрос в конце, ≤ 1 эмодзи, без хэштегов, простой разговорный язык
- [ ] Закреплённый коммент уникален
- [ ] YouTube: заголовок ≤ 100, не для детей, категория/язык
- [ ] Слот свободен, интервал ≥ 4 ч на площадке, ролик ещё не выходил на этой площадке
- [ ] `post_check.py` — 0 ошибок
- [ ] Аня сказала «да» на этот пост
- [ ] После публикации: `request_id` в `post.md`, строка в `history.json` / `log.csv`

## Банк ответов (смысл, не шаблоны — не вставлять один текст под десятками комментов)
| Пишут | Смысл ответа |
|---|---|
| «а как ты получила визу?» | коротко правду + «расскажу подробно в серии N» |
| «сколько стоит жить в Лондоне?» | конкретная цифра из её опыта, если она её давала; иначе «соберу в отдельный ролик» |
| «зачем уезжать?» | спокойно, одна мысль из ролика, без спора |
| хейт / «AI всё испортил» | не спорить; ответить одной фразой или не отвечать |
| вопрос, на который нужен ролик | ответ видео-ответом → идея в `_strategy/ideas` |

## Пробные рилсы (Trial Reels) через Upload-Post — проверено по документации 2026-10-27
- В API Upload-Post есть параметр Instagram `share_mode`: `CUSTOM` (обычный рилс, по умолчанию), `TRIAL_REELS_SHARE_TO_FOLLOWERS_IF_LIKED` (показ неподписчикам, а если за 72 ч зайдёт — Instagram сам покажет подписчикам), `TRIAL_REELS_DONT_SHARE_TO_FOLLOWERS` (только неподписчикам, к подписчикам переводишь вручную в приложении).
- В схеме MCP-инструмента `upload_video` этого параметра нет. `platformOptions` принимает любые ключи, но точное имя ключа (`instagramShareMode`?) не проверено — первый раз проверить на тестовом посте.
- Ограничения API: публичный профессиональный аккаунт, по документации ≥1000 подписчиков, без соавторов (collaborators). Перевод из пробного к подписчикам Meta через API не даёт — только в приложении.
- Postiz (сервис из пайплайна Нади): пробные рилсы в документации не упоминаются.
